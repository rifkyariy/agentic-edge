# Experiment export

Generated by `benchmark/export_experiment.py`, which pulls every figure from
both boards through `run_detail.py` over ssh. Regenerate with:

```bash
python3 benchmark/export_experiment.py --out findings/export/experiment-full.json --raw-telemetry
```

| file | size | contents |
|---|---|---|
| `experiment-full.json.gz` | 2.7 MB | everything, including the model's full answer text |
| `experiment-full.json` | 36 MB | the same, uncompressed (git-ignored) |
| `experiment-metrics.json` | 33 MB | same minus answer text (git-ignored) |

Covers 1,300 requests, 143,425 telemetry samples, 875,007 generated tokens and
309.8 Wh of measured board energy across 13 runs on two boards.

## Shape

```
experiment, exported_at, telemetry_resolution
protocol            task, shots, decoding, subsets + seeds, serving flags,
                    what -rea off means, how power is measured
boards.<pi|jetson>
  label, host, hardware {soc, cpu, gpu, ram_mb, swap_mb, power_sense, llama_flags}
  archived_failed_runs[]
  runs.<run-name>
    model, subset, status, summary {score, stderr, minutes}
    timeline[]        one per request, in order:
                        pt/gt      prompt and generated tokens
                        pms/gms    prefill and decode milliseconds
                        pts/gts    prefill and decode tokens per second
                        start_epoch/end_epoch, t (seconds into the run)
                        dev{}      device conditions across that request's own
                                   window — w_mean, w_max, j (trapezoidal
                                   integral), j_per_token, cpu, gpu, temp_max,
                                   rss_mb, throttled, samples
    telemetry[]       1 Hz: t (relative to first request, negative = the idle
                      baseline before the run), w, cpu, gpu, temp, mem, rss,
                      mhz, mhz_gpu, thr
    summary_json      energy_wh, idle_w, mean_w, peak_w, j_per_token,
                      tok_s_per_w, decode_tok_s, prefill_tok_s, gen_tokens,
                      temp_max, throttled, cpu_mean, gpu_mean/max/mhz_mean
    questions[]       subject, question, options, gold, got, ok, resp, chars
```

## Reading it honestly

- **Two Pi directories predate the subset suffix.** `mmlupro100-e2b` is E2B s1;
  `mmlupro100-e4b` is E4B s1 and is **superseded by** `mmlupro100-e4b-s1` —
  identical data, exported twice because the record keeps both. Count one.
  That is why the totals above say 13 runs and the comparison uses 12.
- **Jetson runs before 2026-09-22 are not here.** They served without
  `-rea off --reasoning-budget -1` and are archived under `stdbench/failed/`;
  `archived_failed_runs` lists them by name.
- **Power is board DC draw**, not wall power — PMIC rails on the Pi, INA3221
  `VDD_IN` on the Jetson. Excludes PSU conversion loss.
- **Negative `t` in telemetry** is the idle baseline `run_measured.sh` records
  before work starts; `idle_w` comes from it.
