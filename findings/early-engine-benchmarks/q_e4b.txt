```python
def fib(n):
    if n <= 0:
        return 0
    elif n == 1:
        return 1
    else:
        a, b = 0, 1
        for _ in range(2, n + 1):
            a, b = b, a + b
        return b
```

===== Q9 =====
Here are a few options, depending on the nuance you want to convey:

**Most Common and Natural:**

> **Cuacanya bagus hari ini, jadi saya ingin keluar dan berjalan-jalan.**

**Slightly more formal:**

> **Hari ini cuacanya menyenangkan, jadi saya ingin pergi keluar dan berjalan.**

**More casual (using "mau"):**

> **Cuacanya enak hari ini, jadi aku mau keluar dan jalan-jalan.**

***

**Breakdown of terms:**

* **The weather is nice today:** *Cuacanya bagus hari ini* (or *Cuacanya menyenangkan*)
* **So:** *Jadi*
* **I want to:** *Saya ingin* (formal/standard) or *Aku mau* (casual)
* **Go outside:** *Keluar* (to go out) or *Pergi keluar*
* **And walk:** *Dan berjalan* (to walk) or *Dan berjalan-jalan* (to take a stroll/walk around, which is often implied in this context
