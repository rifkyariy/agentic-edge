```python
def fib(n):
    if n <= 0:
        return 0
    elif n == 1:
        return 1
    else:
        a, b = 0, 1
        for _ in range(2, n + 1):
            a, b = b, a + b
        return b
```

===== Q9 =====
Here are a few ways to translate "The weather is nice today, so I want to go outside and walk" into Indonesian, depending on the desired nuance:

**Most Common and Natural Translation:**

> **Cuacanya bagus hari ini, jadi saya ingin keluar dan berjalan-jalan.**

**Slightly more casual:**

> **Cuacanya enak hari ini, jadi aku mau keluar dan jalan-jalan.** (Using "aku" instead of "saya" is more informal)

**Breakdown of the words:**

* **The weather:** Cuaca
* **is nice:** bagus (good/nice) or enak (pleasant/nice)
* **today:** hari ini
* **so:** jadi
* **I want to:** saya ingin (formal) / aku mau (informal)
* **go outside:** keluar (to go out)
* **and walk:** dan berjalan-jalan (to walk around/stroll) or dan jalan (and walk)
